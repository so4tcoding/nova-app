# NOVA

시험 범위 요약·문제 풀이, 수행평가 암기 훈련, 펫 키우기와 친구 대전이 있는 공부 앱입니다.

## 설치 (안드로이드)
1. [최신 버전 다운로드](https://github.com/so4tcoding/nova-app/releases/latest/download/nova.apk)
2. 받은 `nova.apk`를 눌러 설치합니다. ('출처를 알 수 없는 앱' 허용 필요)
3. 업데이트는 새 APK를 지우지 말고 덮어 설치하면 기록이 그대로 남습니다.

## 설치 (아이폰 · 아이패드)
1. **Safari**로 <https://so4tcoding.github.io/nova-app/> 를 엽니다. (크롬·카카오톡 안 브라우저 말고 Safari)
2. 아래쪽 **공유** 버튼(네모에 위 화살표) → **홈 화면에 추가** → **추가**.
3. 홈 화면의 NOVA 아이콘으로 열면 앱처럼 전체 화면으로 열립니다. 한 번 연 뒤에는 인터넷 없이도 열립니다.
4. 새 버전이 나오면 앱 아래에 "새 버전이 준비됐어요 → 새로고침"이 뜹니다.

> 아이폰에서는 연락처로 친구 찾기가 안 되고 친구 코드로 추가합니다. 기록은 기기마다 따로 저장되니, 로그인하면 클라우드로 옮겨집니다.
